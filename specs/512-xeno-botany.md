# Xeno-Botany

## 1. Overview
**Layer:** 1
**Fantasy:** The flora is beautiful, useful, and trying to kill you.
**Mechanic:** "Greenhouse" buildings allow cultivation of alien plants found on the map. Researching them unlocks new drugs/materials but carries bio-hazard risks.
**Emergence:** You cultivate "Whisper-Vines" for their mood-boosting pollen, but they grow out of control and strangle your power grid.
**Tension:** Safe Earth crops (low yield) vs. Dangerous Alien crops (high yield/risk).

## 2. Dependencies
- Farming/Hydroponics (`Farm`, `CropType`)
- Hazard system (`Hazard`, `BioHazard`)
- Tech Tree/Research system

## 4. GREEN Phase: Minimal Implementation
```rust
#[derive(Component)]
pub struct Farm {
    pub crop: CropType,
    pub growth: f32,
}

#[derive(Clone, Copy, PartialEq)]
pub enum CropType {
    Wheat,        // Safe
    WhisperVine,  // Alien, hazardous
    StrangleWeed, // Alien, aggressive
}

#[derive(Component)]
pub struct BioHazard {
    pub potency: f32,
}

pub fn harvest_xeno_crop_system(
    mut events: EventReader<HarvestCropEvent>,
    mut commands: Commands,
    mut inventory: ResMut<ColonyInventory>,
    farms: Query<&Farm>,
) {
    for event in events.read() {
        if let Ok(farm) = farms.get(event.farm) {
            match farm.crop {
                CropType::Wheat => inventory.add(ItemType::Food, 10),
                CropType::WhisperVine => {
                    inventory.add(ItemType::WhisperPollen, 20); // High yield
                    commands.entity(event.farm).insert(BioHazard { potency: 5.0 }); // Hazard
                },
                _ => {}
            }
        }
    }
}
```
