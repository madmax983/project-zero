# 884: Ground Survival Start

**Layer:** Startup content / Layer 1 survival
**Status:** Draft
**Complexity:** Medium

---

## 1. Overview

Implement the `GroundSurvival` start scenario as the hardest curated opener.

This start shares the default landing shell, but enters play materially weaker and under sharper environmental pressure. The player should feel immediate survival triage rather than smooth expansion.

---

## 2. Dependencies

- `882` Start Scenario Framework
- Existing survival systems: food, atmosphere, maintenance, and tools

---

## 3. Scope

- Reduce starting material cushion
- Damage or weaken at least one core survival system
- Bias starter population toward fewer immediately useful specialists
- Add scenario-specific intro chronicle text

---

## 4. Acceptance Criteria

- [ ] `GroundSurvival` measurably reduces opening resilience.
- [ ] The shared landing footprint remains unchanged.
- [ ] The scenario has distinct intro messaging.
- [ ] Startup tests can observe scenario-specific resource or system changes.

---

## 5. Notes

- Use concrete problems, not just flat morale penalties.
- Avoid fake difficulty that simply causes an unwinnable spiral.
