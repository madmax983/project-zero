# 1013: The Void Echoes

## 1. Overview
Wrecked fleets on Layer 2 slowly decay, emitting corrupted, looping distress signals. These "Void Echoes" bleed into Layer 1 communications arrays. Pops working near the arrays gain the "Haunted" trait, suffering mood penalties but occasionally gaining strange insights (free random research points). This forces a choice between passive, free research generated by the wreckage and the creeping psychological horror inflicted on communication workers.

## 2. Dependencies
- Layer 2 `Fleet` (wreckage/debris mechanics).
- Layer 1 `Communications` structures.
- Layer 1 `Pop` traits (`Haunted`).
- Layer 1 `Research` system.
- `Mood`/`Stress` system.

#[cfg(test)]
mod tests {
    use super::*;
    use bevy::prelude::*;
    use crate::layer2::fleet::{Wreckage, OrbitalPosition};
    use crate::layer1::structures::CommsArray;
    use crate::layer1::pop::{Pop, Mood};
    use crate::layer1::research::{ResearchPoints, TechCategory};
    use crate::layer1::utility_ai::WorkOrder;

    #[test]
    fn test_comms_workers_become_haunted_by_orbital_wreckage() {
        let mut app = App::new();
        app.add_systems(Update, void_echo_infection_system);

        // Setup Layer 2 Wreckage
        app.world_mut().spawn((
            Wreckage { decay_level: 50.0 },
            OrbitalPosition { x: 0.0, y: 0.0 }, // Over the colony
        ));

        // Setup Layer 1 Comms Worker
        let comms_array = app.world_mut().spawn(CommsArray).id();
        let worker = app.world_mut().spawn((
            Pop,
            WorkOrder { task_type: "OperateComms".to_string(), target: Some(comms_array), ..default() }
        )).id();

        app.update();

        assert!(app.world().get::<HauntedTrait>(worker).is_some(), "Workers operating comms arrays under orbital wreckage should gain the Haunted trait.");
    }

    #[test]
    fn test_haunted_workers_generate_anomalous_research() {
        let mut app = App::new();
        app.insert_resource(ResearchPoints { category: TechCategory::Anomalous, amount: 0.0 });
        app.add_systems(Update, haunted_research_generation_system);

        let worker = app.world_mut().spawn((
            Pop,
            HauntedTrait { severity: 10.0 },
        )).id();

        app.update();

        let research = app.world().resource::<ResearchPoints>();
        assert!(research.amount > 0.0, "Haunted Pops should passively generate Anomalous research over time.");
    }

    #[test]
    fn test_haunted_workers_suffer_mood_penalty() {
        let mut app = App::new();
        app.add_systems(Update, apply_haunted_mood_penalty_system);

        let worker = app.world_mut().spawn((
            Pop,
            Mood { value: 100.0 },
            HauntedTrait { severity: 10.0 },
        )).id();

        app.update();

        let mood = app.world().get::<Mood>(worker).unwrap();
        assert!(mood.value < 100.0, "Haunted trait should drain a Pop's mood.");
    }
}

## 4. GREEN Phase: Minimal Implementation
```rust
// src/layer1/void_echoes.rs
use bevy::prelude::*;
use crate::layer2::fleet::Wreckage;
use crate::layer1::structures::CommsArray;
use crate::layer1::pop::{Pop, Mood};
use crate::layer1::research::{ResearchPoints, TechCategory};
use crate::layer1::utility_ai::WorkOrder;

#[derive(Component)]
pub struct HauntedTrait {
    pub severity: f32,
}

pub fn void_echo_infection_system(
    mut commands: Commands,
    wreckage_query: Query<&Wreckage>,
    worker_query: Query<(Entity, &WorkOrder), With<Pop>>,
    comms_query: Query<Entity, With<CommsArray>>,
) {
    // Only infect if there is active wreckage in orbit
    if !wreckage_query.is_empty() {
        for (entity, work_order) in worker_query.iter() {
            if work_order.task_type == "OperateComms" {
                if let Some(target) = work_order.target {
                    if comms_query.get(target).is_ok() {
                        commands.entity(entity).insert(HauntedTrait {
                            severity: 1.0, // MVP fixed value
                        });
                    }
                }
            }
        }
    }
}

pub fn haunted_research_generation_system(
    query: Query<&HauntedTrait>,
    mut research: ResMut<ResearchPoints>,
) {
    for haunted in query.iter() {
        if research.category == TechCategory::Anomalous {
            // Passive trickle of tech based on severity
            research.amount += haunted.severity * 0.05;
        }
    }
}

pub fn apply_haunted_mood_penalty_system(
    mut query: Query<(&mut Mood, &HauntedTrait)>,
) {
    for (mut mood, haunted) in query.iter_mut() {
        // Mood penalty scales with severity
        mood.value -= haunted.severity * 0.1;
    }
}
```

## 5. REFACTOR Phase: Quality & Design
- **Severity Scaling:** `HauntedTrait` severity should scale with the size/mass of the `Wreckage` overhead.
- **Orbital Positions:** The `void_echo_infection_system` needs to correctly map Layer 2 orbital positions to Layer 1 colony coordinates to ensure the wreckage is actually *above* the colony.
- **Madness/Sabotage:** If `Mood` drops to zero due to the Haunted trait, the Pop should have a chance to switch their `WorkOrder` to actively sabotaging life support, as described in the idea pitch.
