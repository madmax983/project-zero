# 885: Social Drama Start

**Layer:** Startup content / Layer 1 social systems
**Status:** Draft
**Complexity:** Medium

---

## 1. Overview

Implement the `SocialDrama` start scenario as the medium curated opener.

This start should be materially more stable than `GroundSurvival` while being socially more volatile. The colony should function physically, but the people should begin in a strained configuration.

---

## 2. Dependencies

- `078` The Old Guard
- `090`/`346` Emotional Contagion
- `233` Public Grievances
- `882` Start Scenario Framework

---

## 3. Scope

- Alter founder or immigrant composition at startup
- Bias early traits, ethics, or factional distribution toward tension
- Add scenario-specific intro chronicle text
- Surface the social instability through existing systems instead of custom rules where possible

---

## 4. Acceptance Criteria

- [ ] `SocialDrama` starts materially viable but socially unstable.
- [ ] Founder or immigrant composition differs observably from `Classic`.
- [ ] Existing social systems react to the altered composition.
- [ ] The scenario has distinct intro messaging.

---

## 5. Notes

- The opening fantasy is "stable base, unstable society."
- Do not make hunger the primary story in this scenario.
