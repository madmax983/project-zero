# 029: Knowledge System

## Overview

Introduces **Knowledge** as a resource and **Research** as a mechanic.
- **Knowledge**: Generated by pops working at a **Library**.
- **Tech Tree**: Players spend Knowledge to unlock new buildings and bonuses.
- **Unlocks**: Certain buildings (e.g., Smelter, Tavern) now require specific technologies.

This adds a progression layer to the simulation, preventing all content from being available immediately.

## Dependencies

- `018` — Mining & Resources (for `ColonyResources`)
- `016` — Utility AI (for `ActionType::Research` or similar)
- `006` — Building Placement (for `try_place_building`)

### 2. Create `Tech` and `TechState`

```rust
// src/layer1/tech.rs (Create new module)

use bevy_ecs::prelude::*;
use crate::layer1::resources::ColonyResources;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Tech {
    Masonry,
    MetalWorking,
    SocialStructures,
}

impl Tech {
    pub fn cost(&self) -> f32 {
        match self {
            Self::Masonry => 10.0,
            Self::MetalWorking => 20.0,
            Self::SocialStructures => 15.0,
        }
    }

    pub fn label(&self) -> &str {
        match self {
            Self::Masonry => "Masonry",
            Self::MetalWorking => "Metal Working",
            Self::SocialStructures => "Social Structures",
        }
    }
}

#[derive(Resource, Default, Debug)]
pub struct TechState {
    unlocked: std::collections::HashSet<Tech>,
}

impl TechState {
    pub fn is_unlocked(&self, tech: Tech) -> bool {
        self.unlocked.contains(&tech)
    }

    pub fn unlock(&mut self, tech: Tech) {
        self.unlocked.insert(tech);
    }
}

pub fn unlock_tech(world: &mut World, tech: Tech) -> bool {
    let cost = tech.cost();
    let can_afford = {
        let res = world.resource::<ColonyResources>();
        res.knowledge >= cost
    };

    if can_afford {
        world.resource_mut::<ColonyResources>().knowledge -= cost;
        world.resource_mut::<TechState>().unlock(tech);
        // Log message here
        true
    } else {
        false
    }
}
```
