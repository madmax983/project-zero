# 532 The Galactic Relay Strike

## 1. Overview
**Layer:** Cross-layer (Layer 1 -> 3)
**Fantasy:** Your tiny colony becomes the bottleneck for the entire galactic internet, and you hold all the cards.
**Mechanic:** Your system generates with a unique, indestructible precursor "Hyper-Relay." This relay handles all FTL communication for the sector (Layer 3). By physically occupying the relay control room on Layer 1, you can "throttle" or completely shut down comms for neighboring empires.
**Emergence:** Two massive empires go to war. You take control of the relay and demand a massive "maintenance fee" in rare tech from both sides to keep their military communications online. They both agree, turning your primitive mining outpost into the richest, most technologically advanced world in the sector through pure extortion.
**Tension:** The incredible diplomatic leverage and wealth generated by controlling the relay vs. the terrifying reality that every major empire now has a profound strategic interest in conquering your tiny world.

fn test_throttling_comms_generates_diplomatic_pressure() {

    let mut app = setup_world();
    app.world_mut().insert_resource(GalacticCommsStatus { is_throttled: true });

    // Setup a neighboring empire
    let neighbor_id = app.world_mut().spawn((
        Civilization { name: "Empire A".to_string(), ..default() },
        DiplomaticRelations { player_affinity: 50 },
    )).id();

    // Act: Time passes with comms throttled
    for _ in 0..10 {
        app.update();
    }

    // Assert: Affinity drops due to the blockade, or demands are generated
    let relations = app.world().get::<DiplomaticRelations>(neighbor_id).unwrap();
    assert!(relations.player_affinity < 50, "Neighbor affinity should drop when comms are throttled");
}

#[test]
fn test_extortion_trade_deal_accepted_during_war() {
    // Arrange
    let mut app = setup_world();
    app.world_mut().insert_resource(GalacticCommsStatus { is_throttled: true });
    app.world_mut().insert_resource(ColonyResources::default()); // 0 credits initially

    // Empire is at war, so they are desperate
    let empire_id = app.world_mut().spawn((
        Civilization { name: "Empire A".to_string(), ..default() },
        DiplomaticState::AtWar, // High desperation
    )).id();

    // Act: Player offers to unthrottle comms for credits
    app.world_mut().send_event(RelayExtortionOfferEvent {
        target_civilization: empire_id,
        demanded_credits: 5000,
    });
    app.update();

    // Assert: The desperate empire accepted the deal
    let resources = app.world().resource::<ColonyResources>();
    assert_eq!(resources.credits, 5000, "Desperate empire should pay the extortion fee");

    let comms_status = app.world().resource::<GalacticCommsStatus>();
    assert!(!comms_status.is_throttled, "Comms should be restored after extortion is paid");
}

## 4. GREEN Phase: Minimal Implementation

```rust
// In src/layer3/diplomacy/hyper_relay.rs

#[derive(Resource, Default)]
pub struct GalacticCommsStatus {
    pub is_throttled: bool,
}

#[derive(Event)]
pub struct ThrottleRelayEvent {
    pub active: bool,
}

#[derive(Event)]
pub struct RelayExtortionOfferEvent {
    pub target_civilization: Entity,
    pub demanded_credits: u32,
}

pub fn handle_relay_throttle_system(
    mut events: EventReader<ThrottleRelayEvent>,
    mut comms_status: ResMut<GalacticCommsStatus>,
    mut notifications: ResMut<Notifications>,
) {
    for event in events.read() {
        comms_status.is_throttled = event.active;
        if event.active {
            notifications.push(Notification::new("Relay Throttled", "Galactic communications restricted. Neighbors will notice."));
        } else {
            notifications.push(Notification::new("Relay Open", "Galactic communications restored."));
        }
    }
}

pub fn relay_diplomatic_pressure_system(
    comms_status: Res<GalacticCommsStatus>,
    mut civ_query: Query<&mut DiplomaticRelations, With<Civilization>>,
) {
    if comms_status.is_throttled {
        for mut relations in civ_query.iter_mut() {
            // Affinity drops slowly while comms are blocked
            relations.player_affinity = relations.player_affinity.saturating_sub(1);
        }
    }
}

pub fn handle_extortion_offers_system(
    mut events: EventReader<RelayExtortionOfferEvent>,
    mut resources: ResMut<ColonyResources>,
    mut comms_status: ResMut<GalacticCommsStatus>,
    civ_query: Query<&DiplomaticState, With<Civilization>>,
    mut notifications: ResMut<Notifications>,
) {
    for event in events.read() {
        if let Ok(state) = civ_query.get(event.target_civilization) {
            // Simple MVP logic: Only desperate empires (at war) accept the deal
            if matches!(state, DiplomaticState::AtWar) {
                resources.credits += event.demanded_credits;
                comms_status.is_throttled = false;
                notifications.push(Notification::new("Extortion Paid", &format!("Received {} credits. Comms restored.", event.demanded_credits)));
            } else {
                notifications.push(Notification::new("Offer Rejected", "They refused to pay the extortion fee."));
            }
        }
    }
}
```

## 5. REFACTOR Phase: Quality & Design
- **Integration:** Spawning the `HyperRelay` should be tied to map generation (`095 System Generation`). It should be a rare, unique point of interest.
- **Consequences:** Continually extorting empires should increase their `Hostility` to the point where they send a fleet to physically conquer the colony rather than just suffering an affinity drop.
- **UI:** A specific "Relay Control" UI panel in the Command Center is needed to manage the throttling and make demands.
