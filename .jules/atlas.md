## [Breaking the Building God Module]
**Tangle:** `src/layer1/building.rs` was a 3200+ line God Module that imported almost every other module in `layer1` to implement `try_place_building`. Because fundamental types like `BuildingType`, `Building`, and `MaterialType` were locked inside it, many external modules (e.g., `ai_core`, `admin`, `trade`) had to import `layer1::building`. This resulted in over a dozen circular dependencies (e.g., `building` -> `ai_core` -> `building`).
**Blueprint:** Refactored `src/layer1/building.rs` into a module directory `src/layer1/building/` utilizing the Facade pattern via `mod.rs`. The code was split into `types.rs` (data enums and costs), `components.rs` (ECS components), and `placement.rs` (spawning and validation logic). External modules now only depend on `types.rs` and `components.rs`, while `placement.rs` imports the complex external systems, strictly enforcing acyclic, unidirectional dependencies.
