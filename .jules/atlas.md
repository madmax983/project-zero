**The "Blob" Extract - layer1/building**
**Tangle:** `src/layer1/building.rs` grew to over 3,400 lines, becoming a monolith containing foundational types (`BuildingType`, `Direction`), components (`Building`, `Material`), heavy placement logic (`try_place_building`), and extensive UI configuration code for every single building type in the game. This made it a bottleneck for logic changes and compile times.
**Blueprint:** Extracted the monolithic `building.rs` into a well-defined `src/layer1/building` directory containing `mod.rs` (Facade), `types.rs`, `components.rs`, `placement.rs`, and `tests.rs`. All types are explicitly re-exported through the `mod.rs` Facade (`pub use types::*; pub use components::*; pub use placement::*;`) to maintain the public API contract across the dozens of systems that depend on them, preventing a complete rewrite of import paths across the codebase.
