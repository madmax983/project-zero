## 2026-07-09 - The "Nova" Fallback Illusion
**Confusion:** Users believed they had successfully enabled the `nova` feature because the fallback dummy implementations of `OralTradition` compiled and printed hardcoded dummy data without error, contradicting the README which promised an `E0422` error. Furthermore, headless users were confused by the `NarrativeError::to_table()` method, assuming it returned a `comfy_table::Table` and trying to typecast it, when it actually returned a raw `String`.
**Clarification:** Deleted all dummy `#[cfg(not(feature = "nova"))]` structs to ensure the code correctly fails with `E0422` as documented, forcing users to explicitly opt into the feature. Added `ignore` doctest demonstrating the requirement. Clarified `NarrativeError::to_table` docs to explicitly state it returns a `String` and does not leak `comfy-table` types.
